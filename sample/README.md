# 试用样本

本目录提供两本 EPUB，供体验导入流水线与内置阅读器使用：

| 文件 | 作者 | 体裁 |
| :--- | :--- | :--- |
| [钟表馆事件.epub](钟表馆事件.epub) | 绫辻行人 | 长篇小说（"馆"系列代表作） |
| [密室收藏家.epub](密室收藏家.epub) | 大山诚一郎 | 短篇小说集 |

## 为什么选这两本

- 两本书均可在本工具的主要数据源中检索到完整资料 —— 推理小说数据库
  [暗扣 (claspclub)](https://claspclub.com/) 与 [豆瓣](https://book.douban.com/)，
  导入时可以完整体验「claspclub 匹配 → 元数据回填（封面 / 无剧透简介 / 标签 / 系列）→
  豆瓣短评抓取」的全流程；若数据源带有系列信息，还会自动继承系列与卷号；
- 一长一短对应两种常见的 EPUB 形态，可同时检验阅读器的章节解析、
  滚动 / 分页排版与移动端手势表现。

## 使用方式

配合主 README 的[试用指南](../README.md#试用指南)操作：
创建书库后点「＋ 加书」选择本目录下的 EPUB 即可（书籍会复制入书库，原始文件不会被修改）。

> ⚠️ 书籍版权归作者与出版社所有，仅供导入功能测试与个人试读，请勿二次传播。

## 夹带私货：既然下载了，不妨读一读

这两本是特意挑选的，即使你平时不读推理小说，也完全可以放心入坑：

- **《钟表馆事件》（绫辻行人）**：新本格的华丽之巅。篇幅虽厚，可读性却极佳，
  行文流畅、毫无故弄玄虚；既避开了绫辻行人部分作品中偏重的恐怖与猎奇元素，
  又把"馆"系列的看家本领 —— 密闭馆邸 + 华丽到近乎奢侈的核心诡计 —— 发挥得淋漓尽致。
  结局揭晓时的那种震撼，是很多推理小说给不了的。本书还有改编日剧，
  读完对照着看别有一番乐趣。
- **《密室收藏家》（大山诚一郎）**：短篇密室的教科书。整部短篇集平均质量极高、
  没有凑数之作；大山诚一郎的基础功底非常扎实，逻辑推进干净利落，
  对密室手法的梳理讲解更是清晰透彻，非常适合作为推理入门的第一本。

入门路线建议：先读《密室收藏家》——短篇轻量、篇篇有解，练好"本格"的基本功；
意犹未尽再挑战《钟表馆事件》，体验长篇压轴的宏大诡计。读完之后，
欢迎回到书架把状态改成"已读"，让 AI 书虫和你聊聊感想。
